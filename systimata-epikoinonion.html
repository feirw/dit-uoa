Εργαστήριο 1 — Βασικές σημειώσεις MATLAB

Περιβάλλον, πίνακες, πράξεις, γραφικά, M-files, flow control

1. Το περιβάλλον εργασίας (MATLAB Desktop)

Command Window: εκτέλεση εντολών και εμφάνιση αποτελεσμάτων. Με το πλήκτρο ↑ ανακαλείς προηγούμενες εντολές.

Command History: λίστα πρόσφατων εντολών.

Workspace: ενεργές μεταβλητές με όνομα, μέγεθος και τιμή.

Variable Editor: προβολή/επεξεργασία μεταβλητών σε μορφή πίνακα.

clc - Καθαρίζει το Command Window χωρίς να σβήνει μεταβλητές.

clear - Διαγράφει όλες τις μεταβλητές από το Workspace.

help sin - Εμφανίζει βοήθεια για συγκεκριμένη συνάρτηση (π.χ. help cos).

who - Εμφανίζει μόνο τα ονόματα των μεταβλητών στο Workspace.

whos - Εμφανίζει αναλυτικά στοιχεία μεταβλητών (τύπος, bytes, μέγεθος).

ans - Προκαθορισμένη μεταβλητή που κρατά το τελευταίο αποτέλεσμα όταν δεν ορίζεις όνομα μεταβλητής.

2. Διαχείριση και ορισμός πινάκων

Απλός πίνακας: B = [3 5; 9 7] (στήλες με κενό/κόμμα, γραμμές με ;).

Διάνυσμα: πίνακας μίας γραμμής ή μίας στήλης.

Ανάστροφος πίνακας: y = x'.

Με βήμα: A = [αρχή:βήμα:τέλος] ή A = [αρχή:τέλος].

linspace(a, b, n) - Δημιουργεί ακριβώς n ισαπέχουσες τιμές από a έως b.

zeros(M, N) - Πίνακας MxN γεμάτος με μηδενικά.

ones(M, N) - Πίνακας MxN γεμάτος με μονάδες.

rand(M, N) - Πίνακας MxN με τυχαίες τιμές στο διάστημα (0,1).

Indexing (ξεκινά από 1):

X(i, j) στοιχείο γραμμής i, στήλης j.

X(i, :) ολόκληρη γραμμή i.

X(:, j) ολόκληρη στήλη j.

3. Πράξεις και συναρτήσεις

Βασικές πράξεις: +, -, *, /, ^.

Στοιχείο-προς-στοιχείο: .*, ./, .^.

size(A) - Επιστρέφει διαστάσεις πίνακα A, δηλαδή [γραμμές, στήλες].

length(A) - Επιστρέφει το μέγεθος της μεγαλύτερης διάστασης του A.

Συχνές συναρτήσεις: sin, cos, exp, log, sqrt, mean, sum, max, min, round, floor, ceil, fix.

4. Γραφικά (MATLAB Graphics)

plot(x, y) - Σχεδιάζει συνεχή καμπύλη από τα δεδομένα x και y.

stem(n, x) - Σχεδιάζει διακριτά δείγματα (σήματα δειγματοληψίας).

image(C) - Εμφανίζει τον πίνακα C ως εικόνα: κάθε στοιχείο γίνεται pixel με χρώμα ανάλογο της τιμής του. Χρήσιμο για 2D δεδομένα (π.χ. πίνακες, χρονο-συχνότητα, φασματογράμματα). Συχνά συνδυάζεται με colormap και colorbar.

title('...') - Ορίζει τίτλο γραφήματος.

xlabel('...') - Ορίζει ετικέτα άξονα x.

ylabel('...') - Ορίζει ετικέτα άξονα y.

grid on - Ενεργοποιεί πλέγμα στο γράφημα.

legend('...') - Προσθέτει υπόμνημα.

hold on - Κρατά το τρέχον γράφημα ενεργό ώστε το επόμενο plot να σχεδιαστεί πάνω στο ίδιο axes (πολλές καμπύλες μαζί).

hold off - Απενεργοποιεί το hold· τα επόμενα plots ξανά αντικαθιστούν το προηγούμενο.

figure - Δημιουργεί νέο παράθυρο γραφήματος (figure). Χωρίς αυτό, νέα plots μπορεί να αντικαθιστούν το προηγούμενο. Με figure(2) επιλέγεις συγκεκριμένο παράθυρο.

subplot(m,n,p) - Χωρίζει το figure σε m x n θέσεις και ενεργοποιεί την p.

Script files: σειρά εντολών που εκτελείται διαδοχικά.

Function files: ορισμός συνάρτησης με λέξη function, και ίδιο όνομα αρχείου-συνάρτησης.

if ... elseif ... else ... end - Εκτέλεση με συνθήκες (==, ~=, <, >, <=, >=).

while condition - Επανάληψη όσο η συνθήκη είναι αληθής.

Σημείωση: όπου γίνεται, προτιμάμε διανυσματικοποίηση και συναρτήσεις όπως find αντί για loops για καλύτερη απόδοση.

Εργαστήριο 2 — Αναπαράσταση σημάτων στο MATLAB

Εισαγωγή στην αναπαράσταση και επεξεργασία σημάτων συνεχούς και διακριτού χρόνου

1. Ταξινόμηση σημάτων

Σήματα συνεχούς χρόνου (αναλογικά): ορίζονται για κάθε χρονική στιγμή και η τιμή τους μπορεί να είναι οποιοσδήποτε πραγματικός αριθμός.

Σήματα διακριτού χρόνου: ορίζονται μόνο σε συγκεκριμένα χρονικά δείγματα.

Ψηφιακά σήματα: είναι διακριτού χρόνου και διακριτού πλάτους, δηλαδή παίρνουν τιμές από πεπερασμένο σύνολο (π.χ. 0 ή 1).

2. Περιοδικότητα

Περιοδικά σήματα: υπάρχει θετικός αριθμός T (ή N για διακριτά) ώστε x(t)=x(t+T) για όλα τα t.

Απεριοδικά σήματα: δεν παρουσιάζουν επανάληψη.

3. Ενέργεια και ισχύς

Σήματα ενέργειας: πεπερασμένη ενέργεια και μηδενική ισχύς.

Σήματα ισχύος: άπειρη ενέργεια και πεπερασμένη μη μηδενική ισχύς (τυπικά περιοδικά σήματα).

Ένα σήμα δεν ανήκει ταυτόχρονα και στις δύο κατηγορίες.

4. Βασικά σήματα και υλοποίηση στο MATLAB

Για τμηματικά σήματα χρησιμοποιούμε λογικούς τελεστές (>=, <=, &) που δημιουργούν μάσκες 0/1.

Βηματική συνάρτηση u(t): 1 για t>=0 και 0 αλλού.

(t >= 0) - Επιστρέφει 1 όπου ισχύει η συνθήκη, αλλιώς 0.

Συνάρτηση ράμπας r(t): t για t>=0 και 0 για t<0.

t .* (t >= 0) - Πολλαπλασιασμός στοιχείο-προς-στοιχείο με τη μάσκα.

Ημιτονοειδή σήματα: x(t)=A*cos(Omega*t + theta), όπου A πλάτος, Omega κυκλική συχνότητα, theta φάση.

Για ομαλή σχεδίαση χρησιμοποιούμε μικρό βήμα χρόνου (π.χ. pi/30).

Εργαστήριο 3 — Γραμμικότητα και χρονική αμεταβλητότητα

Θεωρία και υλοποίηση ελέγχων ιδιοτήτων συστημάτων στο MATLAB

1. Ορισμός συστήματος

Σύστημα είναι κάθε διάταξη που δέχεται ένα σήμα εισόδου (excitation) και παράγει ένα σήμα εξόδου (response).

Η σχέση εισόδου-εξόδου περιγράφεται από συνάρτηση της μορφής y(t) = f(x(t)).

2. Γραμμικότητα (Linearity)

Ένα σύστημα είναι γραμμικό όταν ικανοποιεί την Αρχή της Υπέρθεσης.

Προσθετικότητα: η απόκριση στο άθροισμα δύο σημάτων ισούται με το άθροισμα των αποκρίσεων.

Ομογένεια: αν πολλαπλασιάσουμε την είσοδο με σταθερά alpha, η έξοδος πολλαπλασιάζεται με την ίδια σταθερά.

Sys{alpha1*x1(t) + alpha2*x2(t)} = alpha1*Sys{x1(t)} + alpha2*Sys{x2(t)}

3. Χρονική αμεταβλητότητα (Time-Invariance)

Σύστημα χρονικά αμετάβλητο σημαίνει ότι τα χαρακτηριστικά του δεν αλλάζουν με τον χρόνο.

Αν καθυστερήσουμε την είσοδο κατά tau: x(t-tau), η έξοδος πρέπει να είναι η αρχική έξοδος με ίδια καθυστέρηση: y(t-tau).

Αν ο χρόνος t εμφανίζεται ρητά στην περιγραφή του συστήματος (π.χ. y(t)=t*x(t)), τότε το σύστημα είναι χρονικά μεταβαλλόμενο.

4. Υλοποίηση στο MATLAB

@(x)... (anonymous functions) για γρήγορο ορισμό συστημάτων σε μία γραμμή.

subplot(m,n,p) για ταυτόχρονη οπτική σύγκριση αναμενόμενης και πραγματικής απόκρισης.

5. Κώδικας — Έλεγχος γραμμικότητας (linearity.m)

MATLAB — linearity.m 
% Script : linearity.m
t = [0:0.01:4];          % Διάνυσμα χρόνου
x1 = cos(2*pi*5*t);      % Σήμα δοκιμής 1
x2 = exp(-0.5*t);        % Σήμα δοκιμής 2
alpha1 = 2;              % Σταθερά 1
alpha2 = 1.25;           % Σταθερά 2

% Σύνθετο σήμα εισόδου
x = alpha1*x1 + alpha2*x2;

% Ορισμός συστημάτων προς έλεγχο
sys_a = @(x) 5*x;        % Γραμμικό
sys_b = @(x) 5*x + 3;    % Μη γραμμικό (+3)
sys_c = @(x) 3*x.*x;     % Μη γραμμικό (τετράγωνο)

% Έλεγχος για το σύστημα (a)
y1 = sys_a(x1);
y2 = sys_a(x2);
y_exp = alpha1*y1 + alpha2*y2; % Αναμενόμενη απόκριση
y_act = sys_a(x);              % Πραγματική απόκριση

% Γραφική σύγκριση
clf;
subplot(1,2,1);
plot(t, y_exp);
title('y_{exp} = \alpha_1 y_1 + \alpha_2 y_2');
xlabel('t (sec)'); ylabel('Amplitude');

subplot(1,2,2);
plot(t, y_act);
title('y_{act} = Sys_a\{\alpha_1 x_1 + \alpha_2 x_2\}');
xlabel('t (sec)'); ylabel('Amplitude');

6. Κώδικας — Έλεγχος χρονικής αμεταβλητότητας (time_invariant_a.m)

MATLAB — time_invariant_a.m 
% Script: time_invariant_a.m
t = [0:0.01:10];                       % Διάνυσμα χρόνου
x = @(t) exp(-0.5*t).*(t>=0);         % Σήμα εισόδου x(t)

% Ορισμός συστημάτων
sys_a = @(x) 5*x;                      % Χρονικά αμετάβλητο
sys_c = @(x) 3*cos(t).*x;              % Χρονικά μεταβαλλόμενο (λόγω cos(t))

% Έλεγχος για το σύστημα (a)
y1 = sys_a(x(t));                      % Έξοδος στο x(t)
y2 = sys_a(x(t-2));                    % Έξοδος στο καθυστερημένο x(t-2)

% Γραφική παράσταση
clf;
plot(t, y1, 'b-', t, y2, 'r--');       % Μπλε συνεχής και κόκκινη διακεκομμένη
title('Responses to x(t) and x(t-2)');
xlabel('t (sec)'); ylabel('Amplitude');
legend('Sys\{x(t)\}', 'Sys\{x(t-2)\}');
grid on;

Εργαστήριο 5 — Τυχαία σήματα

Από το πιο απλό στο πιο σύνθετο

1. Τυχαίοι αριθμοί και κατανομές

Στο Matlab, οι τυχαίοι αριθμοί είναι ψευδοτυχαίοι και ακολουθούν συγκεκριμένες στατιστικές κατανομές.

Ομοιόμορφη κατανομή (Uniform): τιμές με ίδια πιθανότητα στο επιλεγμένο διάστημα.

rand(rows, cols) - Επιστρέφει πίνακα διαστάσεων rows x cols με τιμές στο (0,1).

unifrnd(a, b, M, N) - Επιστρέφει πίνακα M x N με ομοιόμορφες τιμές στο [a,b].

Κανονική κατανομή (Gaussian/Normal): κατανομή με μέση τιμή mu και τυπική απόκλιση sigma.

randn(M, N) - Επιστρέφει πίνακα M x N από την τυπική κανονική (mu=0, sigma=1).

normrnd(mu, sigma, M, N) - Επιστρέφει πίνακα M x N από κανονική με παραμέτρους mu και sigma.

Άλλες κατανομές:

exprnd(mu, ...) - Τυχαίες τιμές από εκθετική κατανομή με μέση τιμή mu.

binornd(n, p, ...) - Τυχαίες τιμές από διωνυμική κατανομή (n δοκιμές, πιθανότητα επιτυχίας p).

poissrnd(lambda, ...) - Τυχαίες τιμές από κατανομή Poisson με παράμετρο lambda.

Οπτικοποίηση:

stem(x) - Διακριτή γραφική παράσταση (δείγματα με κάθετες ράβδους).

hist(x, n) - Ιστόγραμμα με n κάδους (πλήθος τιμών ανά διάστημα).

2. Στατιστικά μεγέθη (περιγραφική στατιστική)

Μέση τιμή: μέσος όρος των τιμών.

mean(x) - Υπολογίζει τη μέση τιμή του x.

Διασπορά: μέσο τετράγωνο απόκλισης από τη μέση τιμή.

var(x) - Υπολογίζει τη διασπορά του x.

Τυπική απόκλιση: τετραγωνική ρίζα της διασποράς.

std(x) - Υπολογίζει την τυπική απόκλιση του x.

3. Σχέση μεταξύ τυχαίων μεταβλητών

Συμμεταβολή (Covariance): μέτρο κοινής μεταβολής δύο μεταβλητών X και Y.

cov(X, Y) - Επιστρέφει τη συμμεταβολή (και πίνακα συμμεταβολών όταν δοθεί πίνακας εισόδου).

Συντελεστής συσχέτισης: μετρά γραμμική συνάφεια δύο μεταβλητών.

corrcoef(X, Y) - Επιστρέφει συντελεστή συσχέτισης rho στο διάστημα [-1,1].

rho = 1: τέλεια θετική συσχέτιση (αυξάνουν μαζί).

rho = -1: τέλεια αρνητική συσχέτιση (όταν αυξάνει η μία, μειώνεται η άλλη).

rho = 0: ασυσχέτιστες μεταβλητές (χωρίς γραμμική συσχέτιση).

4. Τυχαίες διαδικασίες και σήματα

Τυχαίο σήμα: σήμα που εξελίσσεται στον χρόνο με μη απολύτως προβλέψιμο τρόπο.

Πραγματοποίηση (Realization): μία συγκεκριμένη χρονική κυματομορφή από ένα τυχαίο πείραμα.

Σύνολο (Ensemble): το σύνολο όλων των δυνατών πραγματοποιήσεων της ίδιας διαδικασίας.

Κατηγορίες τυχαίων ημιτόνων:

PAM - Τυχαίο πλάτος, σταθερή συχνότητα και φάση.

Τυχαία φάση - Η φάση επιλέγεται συνήθως ομοιόμορφα στο [-pi, pi].

FSK - Τυχαία συχνότητα ανά πραγματοποίηση.

5. Πυκνότητα φάσματος ισχύος (PSD)

PSD: δείχνει πώς κατανέμεται η ισχύς ενός σήματος ως προς τη συχνότητα.

Θεώρημα Wiener-Khinchin: η PSD είναι ο μετασχηματισμός Fourier της αυτοσυσχέτισης.

FFT (Fast Fourier Transform): ο γρήγορος αλγόριθμος υπολογισμού του μετασχηματισμού Fourier. Μεταφέρει ένα σήμα από το πεδίο του χρόνου στο πεδίο της συχνότητας και δείχνει ποιες συχνότητες περιέχει και με πόση «δύνα».

  • Στο MATLAB: fft(x) — υπολογισμός FFT του διανύσματος x
  • fftshift(...) — κεντράρει το φάσμα ώστε το μηδέν Hz να είναι στη μέση του άξονα
  • ifft(...) — αντίστροφος μετασχηματισμός (από συχνότητα πίσω στον χρόνο)

Η PSD και το periodogram βασίζονται στο FFT για να εκτιμήσουν πώς κατανέμεται η ισχύς του σήματος ανά συχνότητα.

Περιοδόγραμμα: απλός μη παραμετρικός εκτιμητής της PSD.

periodogram(x, [], Nfft, Fs) - Εκτιμά PSD του x με Nfft σημεία FFT και συχνότητα δειγματοληψίας Fs.

Λευκός θόρυβος: επίπεδη PSD (ίση ισχύς σε όλες τις συχνότητες), ασυσχέτιστα δείγματα.

WGN: λευκός θόρυβος με Gaussian κατανομή στο πλάτος.

6. Φιλτράρισμα τυχαίων σημάτων

Το φιλτράρισμα χρησιμοποιείται για να κρατήσουμε ή να απορρίψουμε συγκεκριμένες ζώνες συχνοτήτων.

fir1(N, Wn) - Σχεδιάζει χαμηλοπερατό FIR φίλτρο τάξης N με κανονικοποιημένη αποκοπή Wn (0..1).

fir1(N, Wn, 'high') - Σχεδιάζει υψηλοπερατό FIR φίλτρο με ίδια λογική παραμέτρων.

Wn = 1 αντιστοιχεί στη συχνότητα Nyquist (Fs/2).

filter(b, a, x) - Εφαρμόζει το φίλτρο με συντελεστές αριθμητή b και παρονομαστή a στο σήμα x.

Για FIR φίλτρα από τη fir1, συνήθως a = 1.

1. Πραγματοποιήσεις λευκού Gaussian θορύβου (WGN)

MATLAB 
NUM_REAL = 4;
SIMULATION_LENGTH = 1024;
t = 0:(1/SIMULATION_LENGTH):(1-1/SIMULATION_LENGTH);
realizations = zeros(NUM_REAL, SIMULATION_LENGTH);
figure(1);
clf;

for n = 1:NUM_REAL
    realizations(n,:) = randn(1, SIMULATION_LENGTH);
    subplot(NUM_REAL, 1, n);
    plot(t, realizations(n,:));
end

Εργαστήριο 6 & 7 — Κατηγορίες διαμόρφωσης AM

Συνολικό φέρον · DSB-SC · SSB · αποδιαμόρφωση AM · FM & PM

1. Τι είναι διαμόρφωση

Η διαμόρφωση μεταφέρει πληροφορία πάνω σε φέρουσα συχνότητα (carrier) ώστε το σήμα να μπορεί να μεταδίδεται αποδοτικά μέσα από ένα κανάλι επικοινωνίας.

Χωρίς διαμόρφωση, το σήμα δεν μπορεί να μεταφέρει πληροφορία (π.χ. μόνο έναν καθαρό ημίτονο σε υψηλή συχνότητα).

2. Κατηγορίες διαμόρφωσης AM

  • Διαμόρφωση με συνολικό φέρον — κλασική AM, μεταδίδεται το φέρον στη fc
  • Διαμόρφωση με κατηργημένο φέρον (DSB-SC) — διπλή πλευρική ζώνη, χωρίς συνιστώσα φέροντος
  • Διαμόρφωση μονής πλευρικής ζώνης (SSB) — μία πλευρική ζώνη (USB ή LSB)

Διαμόρφωση με συνολικό φέρον

3. Διαμόρφωση πλάτους — AM (συνολικό φέρον)

Στην κλασική AM μεταδίδεται και το φέρον σήμα στη συχνότητα fc (συνολικό φέρον). Το πλάτος του φέροντος μεταβάλλεται ανάλογα με το μήνυμα, ενώ η συχνότητα παραμένει σταθερή.

Σήμα φέροντος (carrier): υψηλής συχνότητας, συνήθως η κεντρική συχνότητα fc.

Μήνυμα (modulating signal): χαμηλότερης συχνότητας fm, ελέγχει το πόσο «δυνατά» γίνεται το φέρον.

Δείκτη βάθους διαμόρφωσης: Mu (0 <= Mu <= 1) — βαθμός βάθους, όχι 100%.

4. Μαθηματική μορφή σήματος AM (συνολικό φέρον)

Το AM σήμα γράφεται ως:

x(t) = Ac * (1 + Mu*cos(2*pi*fm*t)) * cos(2*pi*fc*t)

Ο όρος (1 + Mu*cos(2*pi*fm*t)) περιλαμβάνει τη σταθερή συνιστώσα — μεταδίδεται το συνολικό φέρον στη fc (διαφορά από DSB-SC).

Το (1 + Mu*cos(...)) καθορίζει και το περιβάλλον (envelope). Το cos(2*pi*fc*t) είναι το φέρον υψηλής συχνότητας.

Στο φάσμα (απλός τόνος μηνύματος) εμφανίζονται φέρον στο fc και πλευρικές ζώνες στο fc ± fm. Η μεγαλύτερη συχνότητα είναι:

f_max = fc + fm

5. Περιβάλλον (envelope)

Το περιβάλλον δείχνει πώς αλλάζει το πλάτος του σήματος στον χρόνο.

x_env(t) = abs(Ac * (1 + Mu*cos(2*pi*fm*t)))

Στην πράξη, η περιοχή AM «ακολουθεί» το σχήμα του μηνύματος, ακόμα κι αν το φέρον κρανεί την υψηλή συχνότητα.

Η ανάλυση περιβάλλοντος χρησιμοποιείται στον αποδιαμόρφωση AM (demodulation).

6. Δείκτης διαμόρφωσης μ (Mu)

Ο δείκτης μ καθορίζει πόσο «βαθιά» διαμορφώνεται το φέρον από το μήνυμα. Η τιμή του επηρεάζει άμεσα το σχήμα του περιβάλλοντος και την ποιότητα της μετάδοσης.

Μικρό μ (π.χ. 0.2)

Όταν το μ είναι μικρό:

  • το μήνυμα επηρεάζει λίγο το πλάτος του carrier
  • το envelope έχει μικρές μεταβολές
  • η πληροφορία μεταφέρεται αδύναμα

Αποτέλεσμα: χαμηλή απόδοση πληροφορίας αλλά χωρίς παραμόρφωση

Μέτριο μ (π.χ. 0.7)

Όταν το μ έχει μεσαία τιμή:

  • το μήνυμα αποτυπώνεται καθαρά στο envelope
  • η μετάδοση είναι ισορροπημένη
  • η αποδιαμόρφωση γίνεται εύκολα και σωστά

Αποτέλεσμα: ιδανική και πρακτική λειτουργία AM

μ = 1 (100% διαμόρφωση)

Όταν μ = 1:

  • το envelope φτάνει στο μηδέν στο ελάχιστο σημείο
  • το σήμα αξιοποιεί πλήρως το εύρος του carrier

Αποτέλεσμα: μέγιστη επιτρεπτή διαμόρφωση χωρίς παραμόρφωση

μ > 1 (υπερδιαμόρφωση — overmodulation)

Όταν μ ξεπεράσει το 1:

  • το envelope «αναστρέφεται» (δεν είναι πλέον σωστό περίγραμμα)
  • εμφανίζεται παραμόρφωση
  • ο δέκτης δεν μπορεί να ανακτήσει σωστά το μήνυμα

Αποτέλεσμα: αποτυχία αποδιαμόρφωσης και απώλεια πληροφορίας

Συμπέρασμα

Ο δείκτης διαμόρφωσης μ καθορίζει την ποιότητα της AM μετάδοσης:

  • μικρό μ → αδύναμο σήμα
  • μέτριο μ → σωστή λειτουργία
  • μ = 1 → μέγιστο χωρίς παραμόρφωση
  • μ > 1 → αποτυχία (παραμόρφωση)

7. Αναλογικό σήμα και δειγματοληψία στο MATLAB

Το σήμα στη φύση είναι αναλογικό

Στην πραγματικότητα το AM σήμα είναι:

  • συνεχές στον χρόνο
  • υπάρχει για κάθε t (άπειρες τιμές)

Ο υπολογιστής δεν μπορεί να δουλέψει με συνεχές χρόνο

Στο MATLAB:

  • δεν υπάρχει «συνεχές t»
  • υπάρχουν μόνο δείγματα (samples)

Άρα το σήμα γίνεται t = n·Ts και s[n] — δηλαδή «σπασμένο» σε κομμάτια.

Τι σημαίνει δειγματοληψία εδώ;

Όταν λέμε Ts = 1/fs, σημαίνει:

  • κάθε πόσο χρόνο παίρνουμε μια τιμή του σήματος

Παράδειγμα:

  • fs = 1 MHz
  • Ts = 1 μs

δηλαδή κάθε 1 μικροδευτερόλεπτο παίρνουμε ένα δείγμα.

Θεώρημα Nyquist

Για να μπορούμε να ανακατασκευάσουμε σωστά το σήμα από τα δείγματα, ο ρυθμός δειγματοληψίας πρέπει να ικανοποιεί:

fs >= 2·f_max

  • fs — ρυθμός δειγματοληψίας
  • f_max — μεγαλύτερη συχνότητα που περιέχει το σήμα

Για AM (απλός τόνος): f_max = fc + fm → απαιτείται fs >= 2·(fc + fm).

Αν fs είναι μικρότερο από 2·f_max, εμφανίζεται aliasing (παραμόρφωση λόγω ανεπαρκών δειγμάτων).

  • Ac — πλάτος φέροντος (amplitude carrier)
  • Mu — δείκτης βάθους διαμόρφωσης (modulation index)
  • fc — συχνότητα φέροντος (carrier frequency)
  • fm — συχνότητα μηνύματος (message frequency)

Διαμόρφωση με κατηργημένο φέρον (DSB-SC)

12. Η έννοια του κατηργημένου φέροντος (DSB-SC)

Στην κλασική AM, ένα μεγάλο μέρος της συνολικής ισχύος (πάνω από 66%) καταναλώνεται για τη μετάδοση της φέρουσας συχνότητας fc, η οποία όμως δεν περιέχει καμία πληροφορία. Η πληροφορία βρίσκεται μόνο στις πλευρικές ζώνες.

DSB-SC (Double Sideband Suppressed Carrier): καταργούμε (φιλτράρουμε) το φέρον σήμα και μεταδίδουμε μόνο τις δύο πλευρικές ζώνες (άνω και κάτω).

13. Μαθηματική αναπαράσταση DSB-SC

Η παραγωγή του σήματος DSB-SC είναι μαθηματικά ένας απλός πολλαπλασιασμός του σήματος πληροφορίας m(t) με το φέρον c(t):

s(t) = m(t) · cos(2π·fc·t)

Πλάτος: Το πλάτος του διαμορφωμένου σήματος είναι μηδέν όταν η πληροφορία m(t) είναι μηδέν.

Αλλαγή φάσης: Κάθε φορά που το σήμα m(t) αλλάζει πρόσημο (από θετικό σε αρνητικό), η φάση του διαμορφωμένου σήματος αλλάζει κατά 180°.

14. Φάσμα σήματος DSB-SC

Το φάσμα αποτελείται από δύο «αντίγραφα» του φάσματος της πληροφορίας, μετατοπισμένα γύρω από τη συχνότητα fc:

  • Άνω πλευρική ζώνη (USB): fc + fm
  • Κάτω πλευρική ζώνη (LSB): fc - fm

Απουσία φέροντος: Στη συχνότητα fc, η ισχύς είναι μηδενική.

Για απλό τόνο μηνύματος, η μέγιστη συχνότητα του διαμορφωμένου σήματος είναι f_max = fc + fm.

15. Πλεονεκτήματα και μειονεκτήματα DSB-SC

Πλεονέκτημα: Μεγάλη οικονομία ισχύος, αφού όλη η ενέργεια πηγαίνει στην πληροφορία.

Μειονέκτημα: Η αποδιαμόρφωση είναι πολύ πιο δύσκολη. Δεν μπορεί να χρησιμοποιηθεί απλός φωρατής περιβάλλουσας (envelope detector).

Απαιτείται σύγχρονη αποδιαμόρφωση (coherent detection): ο δέκτης πρέπει να αναγεννήσει το φέρον σήμα σε πλήρη συγχρονισμό φάσης με τον πομπό.

Διαμόρφωση μονής πλευρικής ζώνης (SSB)

18. Εισαγωγή και σκοπός

Στις διαμορφώσεις AM και DSB-SC (διπλής πλευρικής ζώνης), το απαιτούμενο εύρος ζώνης μετάδοσης είναι το διπλάσιο του εύρους του σήματος πληροφορίας:

B_trans = 2 · B_info

Το φάσμα καταλαμβάνεται κατά το ήμισυ από την Άνω Πλευρική Ζώνη (USB) και κατά το άλλο ήμισυ από την Κάτω Πλευρική Ζώνη (LSB).

Λόγω της συμμετρίας γύρω από τη συχνότητα του φέροντος (fc), και οι δύο ζώνες περιέχουν την ίδια ακριβώς πληροφορία.

19. Το σύστημα απλής πλευρικής ζώνης (SSB)

Η τεχνική SSB εκμεταλλεύεται τη συμμετρία αυτή, μεταδίδοντας μόνο τη μία από τις δύο πλευρικές ζώνες.

  • Πλεονέκτημα εύρους ζώνης: Ο δίαυλος απαιτεί εύρος ίσο μόνο με αυτό του σήματος βασικής ζώνης (B_trans = B_info).
  • Οικονομία ισχύος: Μειώνεται η ισχύς μετάδοσης, καθώς δεν σπαταλάται ενέργεια για περιττή (διπλή) πληροφορία.

20. Μέθοδος φιλτραρίσματος (frequency discrimination)

Ένα σήμα SSB μπορεί να δημιουργηθεί αν περάσουμε ένα σήμα DSB-SC από ένα ιδανικό φίλτρο που επιλέγει την επιθυμητή ζώνη.

Το φάσμα του σήματος DSB-SC:

X_DSB(f) = (1/2) · Ac · [M(f - fc) + M(f + fc)]

Τύποι φίλτρων επιλογής:

  • Άνω πλευρική ζώνη (USB): υψηλοπερατό φίλτρο (high-pass) — επιτρέπει συχνότητες πάνω από fc. Hu(f) = 1 για |f| > fc, 0 αλλού.
  • Κάτω πλευρική ζώνη (LSB): βαθυπερατό φίλτρο (low-pass) — επιτρέπει συχνότητες κάτω από fc. Hl(f) = 1 για |f| < fc, 0 αλλού.

21. Μαθηματική έκφραση στον χρόνο (μετασχηματισμός Hilbert)

Στο πεδίο του χρόνου, η έκφραση του σήματος x_SSB(t) είναι πιο σύνθετη από την απλή AM, διότι βασίζεται στον μετασχηματισμό Hilbert.

Έστω σήμα πληροφορίας m(t). Το διαμορφωμένο σήμα SSB:

x_SSB(t) = Ac·m(t)·cos(2π·fc·t) ∓ Ac·m_hat(t)·sin(2π·fc·t)

Όπου:

  • Ac — πλάτος φέροντος
  • fc — συχνότητα φέροντος
  • m_hat(t) — μετασχηματισμός Hilbert του m(t) (μετατόπιση φάσης -90° σε όλες τις συχνότητες)

Το πρόσημο (∓):

  • Πλην (−): Άνω πλευρική ζώνη (USB)
  • Συν (+): Κάτω πλευρική ζώνη (LSB)

Αποδιαμόρφωση AM — Σύγχρονη φώραση

25. Ορισμός και σκοπός

Η αποδιαμόρφωση είναι η αντίστροφη διαδικασία της διαμόρφωσης. Σκοπός της είναι η ανάκτηση του σήματος πληροφορίας βασικής ζώνης m(t) από το διαμορφωμένο σήμα s(t).

Επειδή κατά τη διαμόρφωση το φάσμα μετατοπίστηκε γύρω από τη συχνότητα του φέροντος (fc), στην αποδιαμόρφωση πρέπει να μετατοπιστεί πίσω στην περιοχή των χαμηλών συχνοτήτων (γύρω από το 0).

26. Η διαδικασία της σύγχρονης φώρασης (coherent detection)

Η μέθοδος αυτή ονομάζεται «σύγχρονη» γιατί απαιτεί στον δέκτη ένα τοπικό σήμα που να έχει την ίδια ακριβώς συχνότητα και φάση με τον φέροντα που χρησιμοποιήθηκε στον πομπό.

Βήματα υλοποίησης:

  • Πολλαπλασιασμός: Το λαμβανόμενο σήμα s(t) πολλαπλασιάζεται με ένα τοπικά παραγόμενο ημίτονο cos(2π·fc·t).
  • Φιλτράρισμα: Το αποτέλεσμα περνάει από βαθυπερατό φίλτρο (LPF) για να κρατήσουμε μόνο την πληροφορία και να απορρίψουμε τις υψηλές συχνότητες.

27. Μαθηματική ανάλυση

Έστω το διαμορφωμένο σήμα AM:

s(t) = Ac · [1 + ka·m(t)] · cos(2π·fc·t)

Μετά τον πολλαπλασιασμό με το τοπικό σήμα cos(2π·fc·t):

U(t) = s(t) · cos(2π·fc·t)

U(t) = Ac · [1 + ka·m(t)] · cos²(2π·fc·t)

Με την ταυτότητα cos²(θ) = (1 + cos(2θ)) / 2:

U(t) = (1/2) · Ac · [1 + ka·m(t)] · [1 + cos(4π·fc·t)]

Το U(t) αποτελείται από δύο κύρια μέρη:

  • Όρος βασικής ζώνης: (1/2)·Ac + (1/2)·Ac·ka·m(t) — περιέχει την πληροφορία
  • Όρος υψηλής συχνότητας: (1/2)·Ac · [1 + ka·m(t)] · cos(4π·fc·t) — γύρω από τη συχνότητα 2·fc

28. Ο ρόλος του βαθυπερατού φίλτρου (LPF)

Το σήμα U(t) περιέχει την πληροφορία m(t) αλλά και ανεπιθύμητα στοιχεία σε διπλάσια συχνότητα (2·fc).

Εφαρμόζοντας βαθυπερατό φίλτρο, ο όρος στο 2·fc κόβεται. Στην έξοδο:

y_out(t) = (1/2)·Ac + (1/2)·Ac·ka·m(t)

Με πυκνωτή σύζευξης (αφαίρεση της DC συνιστώσας Ac/2) και ενισχυτή, ανακτούμε το αρχικό σήμα m(t).

Διαμόρφωση γωνίας (FM & PM)

Θεωρητικές σημειώσεις — διαμόρφωση φάσης και συχνότητας

1. Γενική μορφή και ορισμοί

Στη διαμόρφωση γωνίας, το πλάτος του φέροντος παραμένει σταθερό (Ac), αλλά η γωνία θ_i(t) μεταβάλλεται ανάλογα με το σήμα πληροφορίας m(t).

Γενική μορφή διαμορφωμένου σήματος:

s(t) = Ac · cos(θ_i(t))

Σχέση στιγμιαίας γωνίας και στιγμιαίας συχνότητας:

f_i(t) = (1 / 2π) · dθ_i(t) / dt

2. Διαμόρφωση φάσης (PM)

Στην PM, η στιγμιαία γωνία μεταβάλλεται γραμμικά με το m(t):

θ_i(t) = 2π·fc·t + kp·m(t)

  • kp — ευαισθησία φάσης (rad/volt)

Τύπος σήματος PM:

s(t) = Ac · cos[2π·fc·t + kp·m(t)]

3. Διαμόρφωση συχνότητας (FM)

Στην FM, η στιγμιαία συχνότητα μεταβάλλεται γραμμικά με το m(t):

f_i(t) = fc + kf·m(t)

  • kf — ευαισθησία συχνότητας (Hz/volt)

Ολοκληρώνοντας τη συχνότητα για την γωνία:

θ_i(t) = 2π·fc·t + 2π·kf · ∫ m(τ) dτ (από 0 έως t)

Τύπος σήματος FM:

s(t) = Ac · cos[2π·fc·t + 2π·kf · ∫ m(τ) dτ]

4. Χαρακτηριστικά και διαφορές από την AM

  • Περιβάλλουσα: Στην PM και FM η περιβάλλουσα είναι σταθερή (Ac). Στην AM μεταβάλλεται με την πληροφορία.
  • Μηδενισμοί (zero crossings): Λόγω μεταβολής της γωνίας, οι στιγμές μηδενισμού δεν έχουν σταθερές αποστάσεις — βασικό γνώρισμα διαμορφώσεων γωνίας.

5. Διαμόρφωση FM από απλό τόνο

Έστω m(t) = Am · cos(2π·fm·t).

Α. Απόκλιση συχνότητας (Δf)

Μέγιστη μετατόπιση από τη συχνότητα φέροντος:

Δf = kf · Am

Στιγμιαία συχνότητα:

f_i(t) = fc + Δf · cos(2π·fm·t)

Β. Δείκτης διαμόρφωσης (β)

β = Δf / fm

Γ. Τελική κυματομορφή FM (απλός τόνος)

θ_i(t) = 2π·fc·t + β · sin(2π·fm·t)

s(t) = Ac · cos[2π·fc·t + β · sin(2π·fm·t)]

6. Συμπεράσματα

  • Η απόκλιση συχνότητας Δf εξαρτάται μόνο από το Am και είναι ανεξάρτητη από το fm.
  • Ο δείκτης διαμόρφωσης β καθορίζει το εύρος ζώνης του FM στο φάσμα.
  • kf = Δf / Am ή kf = β · fm / Am

7. Φάσμα FM και ρόλος του β

Δοκίμασε να αλλάξεις την τιμή του συντελεστή β και παρατήρησε πώς αλλάζει το φάσμα.

Το φάσμα της κυματομορφής FM περιέχει:

  • μία συνιστώσα που οφείλεται στο φέρον (fc)
  • πλευρικές συχνότητες συμμετρικά εκατέρωθεν του φέροντος, σε διαστήματα fm, 2·fm, 3·fm, …

Στην ειδική περίπτωση μικρού β (β << 1), η FM αποτελείται ουσιαστικά από ένα ζεύγος πλευρικών συχνοτήτων: fc ± fm.

Εργαστήριο 8 & 9 — Κβάντιση και Δειγματοληψία

Δειγματοληψία · ανακατασκευή · ομοιόμορφη κβάντιση · SNR

1. Η διαδικασία της δειγματοληψίας (sampling)

Η δειγματοληψία είναι η γέφυρα μεταξύ του αναλογικού και του ψηφιακού κόσμου: μετατρέπει συνεχές σήμα x(t) σε ακολουθία δειγμάτων.

  • Περίοδος δειγματοληψίας (Ts): χρονικό διάστημα ανάμεσα σε δύο διαδοχικές μετρήσεις
  • Συχνότητα δειγματοληψίας (fs): ρυθμός λήψης δειγμάτων, fs = 1 / Ts
  • Κριτήριο Nyquist: για αποφυγή aliasing, fs >= 2 · f_max

2. Μαθηματική αναπαράσταση

Το δειγματοληπτημένο σήμα x_delta(t) αναπαρίσταται ως σειρά συναρτήσεων δέλτα:

x_delta(t) = Σ x(n·Ts) · δ(t - n·Ts) (για όλα τα n)

Φάσμα δειγματοληπτημένου σήματος

Ο μετασχηματισμός Fourier δείχνει περιοδική επανάληψη του φάσματος του αρχικού σήματος στο πλέγμα συχνοτήτων k / Ts (k ακέραιος):

X_delta(f) = (1/Ts) · Σ X(f - k/Ts) (για όλα τα k)

3. Θεώρημα Nyquist-Shannon

Καθορίζει το ελάχιστο πλήθος δειγμάτων για πλήρη ανακατασκευή του αναλογικού σήματος χωρίς σφάλμα.

Βασική προϋπόθεση: Για σήμα περιορισμένου φάσματος με μέγιστη συχνότητα f_max:

fs >= 2 · f_max

Συχνότητα Nyquist: 2 · f_max

Για διαμορφωμένο σήμα AM (απλός τόνος): f_max = fc + fm.

4. Επικάλυψη (aliasing)

Αν fs < 2 · f_max (δεν τηρείται το κριτήριο Nyquist), εμφανίζεται aliasing.

  • οι περιοδικές επαναλήψεις του φάσματος επικαλύπτονται
  • χάνεται πληροφορία
  • δεν είναι δυνατή ακριβής ανακατασκευή του αρχικού x(t)

5. Ανακατασκευή σήματος (reconstruction)

Η ανακατασκευή επιστρέφει από τα ψηφιακά δείγματα στο αρχικό αναλογικό σήμα.

  • Μετατροπή D/A: ο μετατροπέας παράγει στενούς παλμούς (κρούσεις) με ύψος ανάλογο της τιμής κάθε δείγματος
  • Ιδανικό βαθυπερατό φίλτρο (LPF): «κόβει» τις υψηλές συχνότητες και κρατά μόνο τη βασική ζώνη πληροφορίας
  • Συνθήκη φίλτρου: το εύρος διέλευσης W πρέπει να ικανοποιεί f_max <= W < fs/2

6. Φίλτρο ανακατασκευής και σφάλμα αποκοπής

Η ανακατασκευή στον χρόνο:

x(t) = Σ x(n·Ts) · sinc((t - n·Ts) / Ts) (για όλα τα n)

Συνάρτηση sinc: συνδέει τα δείγματα — κάθε x(n·Ts) πολλαπλασιάζεται με μετατοπισμένη sinc και το άθροισμα δίνει το συνεχές σήμα.

Σφάλμα αποκοπής (truncation error):

  • θεωρητικά η άθροιση είναι από -∞ έως +∞
  • στην πράξη χρησιμοποιούμε πεπερασμένο πλήθος δειγμάτων N
  • χάνεται η συνεισφορά δειγμάτων εκτός του παραθύρου παρατήρησης

7. Σύνοψη στο πεδίο της συχνότητας

Η δειγματοληψία προκαλεί περιοδική επανάληψη του φάσματος ανά διαστήματα fs.

Το ιδανικό βαθυπερατό φίλτρο ανακατασκευής απομονώνει την κεντρική επανάληψη (γύρω από το 0) και επαναφέρει το σήμα στην αρχική μορφή.

  • Αναλογικό σήμα: συνεχές x(t)
  • Διακριτό σήμα: ακολουθία S(n·Ts)
  • Κριτήριο Nyquist: fs >= 2 · f_max

8. Παράδειγμα — Συνεχές σήμα και δειγματοληψία

Σύγκριση συνεχούς ημιτόνου με τα δείγματά του στον ίδιο άξονα (hold on).

MATLAB — Συνεχές vs δείγματα

12. Παράδειγμα — Ανακατασκευή με sinc

Ανακατασκευή δειγματοληπτημένου σήματος με τον τύπο sinc (άθροισμα παλμών).

13. Άσκηση — x(t) = cos(8t) + cos(26t) και 3 περίοδοι Ts

Θέμα: Δίνεται το αναλογικό σήμα x(t) = cos(8t) + cos(26t). Χρησιμοποιήστε 3 διαφορετικές περιόδους δειγματοληψίας και μελετήστε την επίδρασή τους στην ανακατασκευή του σήματος.

Λύση (παράδειγμα): Τρεις τιμές Ts — καλή, οριακή και κάτω από Nyquist.

MATLAB — Άσκηση ανακατασκευής 
tmax = 2*pi;                         % Διάρκεια παρατήρησης (sec)
Ts_vals = [0.02, 0.08, 0.25];        % 3 περίοδοι δειγματοληψίας (sec)

figure;                              % Νέο figure για τα 3 πειράματα

for k = 1:3                          % Για κάθε Ts
    Ts = Ts_vals(k);                 % Τρέχουσα περίοδος δειγματοληψίας
    fs = 1/Ts;                       % Συχνότητα δειγματοληψίας (Hz)
    n = 0:Ts:tmax;                   % Στιγμές δειγματοληψίας
    G = cos(8*n) + cos(26*n);        % Δείγματα x(n·Ts)

    n1 = n;                          % Άξονας χρόνου δειγμάτων
    gr = zeros(size(G));             % Ανακατασκευή

    for i = 1:length(G)              % Βρόχος sinc ανακατασκευής
        gr(i) = sum(G .* sinc(fs*(n(i) - n1)));
    end

    subplot(3,2,2*k-1);              % Αριστερά: δείγματα
    plot(n, G, 'o-');
    title(['Δείγματα, Ts = ', num2str(Ts), ', fs = ', num2str(fs), ' Hz']);
    xlabel('n');
    grid on;

    subplot(3,2,2*k);                % Δεξιά: ανακατασκευή
    plot(n, gr, '-');
    title(['Ανακατασκευή gr, Ts = ', num2str(Ts)]);
    xlabel('n');
    grid on;
end

Παρατήρηση: Με μικρό Ts (μεγάλο fs) η ανακατασκευή πλησιάζει το αρχικό σήμα. Με μεγαλύτερο Ts (μικρότερο fs, κάτω από Nyquist) εμφανίζεται παραμόρφωση.

Κβάντιση — Ομοιόμορφη (σταθερό βήμα Δ)

14. Τι είναι η κβάντιση

Η κβάντιση είναι η διαδικασία όπου ένα αναλογικό σήμα (συνεχές) μετατρέπεται σε πεπερασμένες στάθμες.

  • δεν έχουμε άπειρες τιμές
  • έχουμε «σκαλοπάτια» (επίπεδα)

15. Δ, L και R

Δ (Delta) — βήμα κβάντισης

Η απόσταση μεταξύ δύο διαδοχικών επιπέδων. Όσο μικρότερο το Δ, τόσο πιο ακριβές το σήμα και μικρότερος ο θόρυβος.

L — αριθμός σταθμών

Πόσα επίπεδα έχει ο κβαντιστής.

  • L = 8 → 8 δυνατές τιμές
  • L = 256 → πολύ πιο «λεπτό» σήμα

R — bits

Τα bits που χρειάζονται για να περιγράψουμε τα επίπεδα.

Σχέση: L = 2^R (με R bits έχουμε 2^R συνδυασμούς)

Παράδειγμα: L = 70

  • 2^6 = 64 — δεν φτάνει
  • 2^7 = 128 — καλύπτει τις 70 στάθμες

Άρα χρειάζονται R = 7 bit.

16. Δυνάμεις του 2 (πρόχειρο)

Βοηθητικός πίνακας — τα ψηφιακά συστήματα βασίζονται στο δυαδικό.

  • 2^0 = 1, 2^1 = 2, 2^2 = 4, 2^3 = 8
  • 2^4 = 16, 2^5 = 32, 2^6 = 64, 2^7 = 128
  • 2^8 = 256 — σημαντικό (8-bit PCM audio)
  • 2^9 = 512, 2^10 = 1024 (KB μέγεθος)

Χρησιμοποιείται παντού σε τηλεπικοινωνίες.

17. Βήμα κβάντισης Δ και bitrate

Θεμελιώδης τύπος:

Δ = V_pp / L

όπου V_pp = x_max - x_min

Συμμετρικό σήμα (x_max = A, x_min = -A):

Δ = 2A / L (SOS)

Πρακτικά:

  • μεγάλο L → μικρό Δ → καλύτερη ποιότητα
  • μικρό L → μεγάλο Δ → παραμόρφωση

Bitrate (ρυθμός μετάδοσης): W = Fs · R (bps)

δείγματα ανά δευτερόλεπτο × bits ανά δείγμα

18. Mid-rise και Mid-tread κβαντιστής

Δύο τρόποι να «στηθούν» τα σκαλοπάτια κβάντισης.

Mid-rise κβαντιστής

  • L άρτιος (2, 4, 6, …)
  • δεν έχει επίπεδο στο 0 — το 0 είναι «μεσαίο κενό»
  • στάθμες: +Δ/2, +3Δ/2, +5Δ/2, … και -Δ/2, -3Δ/2, -5Δ/2, …
  • όλα μετατοπισμένα κατά Δ/2

Mid-tread κβαντιστής

  • L περιττός (1, 3, 5, 7, …)
  • έχει επίπεδο στο 0
  • στάθμες: 0, ±Δ, ±2Δ, ±3Δ, …
  • πιο φυσικός για σήματα με μηδενικό μέσο όρο

Σύντομη διαφορά: Mid-rise → χωρίς στάθμη 0 · Mid-tread → με στάθμη 0

19. Σφάλμα κβάντισης, SNR και σύνοψη

Ορισμός σφάλματος

q_i = x_real - x_quantized — πόσο «λάθος» έγινε η προσέγγιση

SOS: |q_i| <= Δ / 2 (ποτέ δεν ξεπερνάς μισό βήμα)

Η κβάντιση πάντα εισάγει θόρυβο.

SNR (Signal to Noise Ratio)

SNR = 10 · log10(SQNR) — πόσο καλό είναι το σήμα σε σχέση με τον θόρυβο (dB)

SQNR = σ_x^2 / σ_q^2 — ισχύς σήματος / ισχύς σφάλματος

Ισχύς σήματος (ημίτονο πλάτους A)

σ_x^2 = A^2 / 2 — βασικό αποτέλεσμα τηλεπικοινωνιών

Ισχύς σφάλματος κβάντισης

  • Θεωρητικά: σ_q^2 = Δ^2 / 12 (ομοιόμορφος θόρυβος κβάντισης)
  • Πρακτικά: σ_q^2 = (q_1^2 + q_2^2 + ... + q_n^2) / n

Τι πρέπει να κρατήσεις

Η κβάντιση:

  • σπάει το σήμα σε επίπεδα (L)
  • εισάγει σφάλμα (q)
  • περιορίζει την ακρίβεια (Δ)
