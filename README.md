# DIT UoA — Προσωπικό αρχείο μαθημάτων

Συλλογή σημειώσεων, διαλέξεων, εργαστηρίων, εργασιών και παλαιών θεμάτων από το Τμήμα Πληροφορικής και Τηλεπικοινωνιών του Εθνικού και Καποδιστριακού Πανεπιστημίου Αθηνών.

Το repository λειτουργεί ταυτόχρονα ως προσωπικό αρχείο σπουδών και ως στατική ιστοσελίδα για γρήγορη πλοήγηση στο διαθέσιμο υλικό.

## Περιεχόμενα

### 1ο εξάμηνο

- Γραμμική Άλγεβρα
- Διακριτά Μαθηματικά
- Εισαγωγή στην Πληροφορική και στις Τηλεπικοινωνίες
- Εισαγωγή στον Προγραμματισμό
- Λογική Σχεδίαση

### 2ο εξάμηνο

- Ανάλυση Ι
- Αρχιτεκτονική Υπολογιστών Ι
- Δομές Δεδομένων και Τεχνικές Προγραμματισμού
- Ηλεκτρομαγνητισμός, Οπτική και Σύγχρονη Φυσική

### 3ο εξάμηνο

- Ανάλυση ΙΙ
- Αντικειμενοστραφής Προγραμματισμός
- Πιθανότητες και Στατιστική
- Σήματα και Συστήματα

### 4ο εξάμηνο

- Αλγόριθμοι και Πολυπλοκότητα
- Δίκτυα Επικοινωνιών Ι
- Συστήματα Επικοινωνιών
- Σχεδίαση και Χρήση Βάσεων Δεδομένων
- Παιδαγωγική Ψυχολογία
- Διοίκηση Έργων

## Δυνατότητες της ιστοσελίδας

- Οργάνωση του υλικού ανά εξάμηνο και μάθημα.
- Άμεση πρόσβαση σε PDF, εικόνες, εργασίες και παλιά θέματα.
- Ξεχωριστές σελίδες μαθημάτων με κατηγοριοποιημένους πόρους.
- Θεματικοί οδηγοί και παραδείγματα κώδικα για επιλεγμένα μαθήματα.
- Επισήμανση σύνταξης κώδικα μέσω Highlight.js.
- Αντιγραφή παραδειγμάτων κώδικα στο πρόχειρο.
- Προσαρμοσμένη εμφάνιση για υπολογιστές και κινητές συσκευές.

- HTML5

## Τοπική εκτέλεση

Δεν χρειάζεται εγκατάσταση εξαρτήσεων. Μετά την κλωνοποίηση του repository:

```bash
git clone https://github.com/feirw/dit-uoa.git
cd dit-uoa
```

Μπορείς είτε να ανοίξεις το `index.html` απευθείας στον browser είτε να ξεκινήσεις έναν απλό τοπικό server:

```bash
python -m http.server 8000
```

Έπειτα άνοιξε τη διεύθυνση [http://localhost:8000](http://localhost:8000).

Η χρήση τοπικού server προτείνεται, επειδή ορισμένοι browsers περιορίζουν λειτουργίες JavaScript όταν μια σελίδα ανοίγει απευθείας από το σύστημα αρχείων.

## Προσθήκη ή ενημέρωση υλικού

1. Πρόσθεσε τα αρχεία στον αντίστοιχο φάκελο μαθήματος.
2. Ενημέρωσε τη σχετική σελίδα HTML με τους νέους συνδέσμους.
3. Αν πρόκειται για νέο μάθημα, δημιούργησε νέα σελίδα και πρόσθεσέ την στο `index.html`.
4. Έλεγξε τοπικά ότι οι σύνδεσμοι ανοίγουν σωστά και ότι η σελίδα παραμένει εύχρηστη σε κινητό.
5. Χρησιμοποίησε σχετικό και περιγραφικό μήνυμα commit.

Για να παραμένει συνεπής η δομή, προτίμησε φακέλους όπως `ΔΙΑΛΕΞΕΙΣ`, `ΕΡΓΑΣΙΕΣ`, `ΕΡΓΑΣΤΗΡΙΟ` και `ΠΑΛΙΑ ΘΕΜΑΤΑ`, όπου αυτό είναι πρακτικό.

## Μεγάλα αρχεία

Το GitHub δεν δέχεται μεμονωμένα αρχεία μεγαλύτερα από 100 MB. Τα αντίστοιχα PDF καταγράφονται στο `.gitignore` και παραμένουν μόνο τοπικά. Επομένως, ορισμένοι σύνδεσμοι ενδέχεται να μην είναι διαθέσιμοι σε ένα νέο clone.

Πριν προστεθεί νέο αρχείο:

- έλεγξε το μέγεθός του,
- συμπίεσέ το όταν είναι δυνατό,
- απόφυγε προσωρινά αρχεία και διπλότυπα,
- χρησιμοποίησε εξωτερική αποθήκευση ή Git LFS, αν απαιτείται διαμοιρασμός πολύ μεγάλων αρχείων.

## Δημοσίευση

Επειδή η εφαρμογή είναι στατική, μπορεί να δημοσιευτεί απευθείας μέσω GitHub Pages:

1. Άνοιξε **Settings → Pages** στο repository.
2. Επίλεξε δημοσίευση από branch.
3. Όρισε το `main` και τον φάκελο `/ (root)`.
4. Αποθήκευσε τις ρυθμίσεις και περίμενε να ολοκληρωθεί η ανάπτυξη.
